# Customer_behaviour_analysis-
Data analytics project showcasing customer behaviour using python,sql,power bi# End-to-End Data Analytics Project | Python, SQL & Power BI

This project demonstrates a complete end-to-end data analytics workflow, transforming raw data into meaningful business insights using Python, SQL, and Power BI.

The project covers data loading, Exploratory Data Analysis (EDA), data cleaning, and preprocessing using Python. SQL is used to perform data extraction, filtering, aggregation, and complex analytical queries. The processed data is then used to build an interactive Power BI dashboard to visualize key metrics, identify trends, and support data-driven decision-making.

A detailed analytical report is prepared to communicate the findings, along with a PowerPoint presentation created using Gamma to present the project outcomes professionally.

**Key Components:**
- Data Loading and Exploration using Python
- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- SQL Analysis using MySQL / PostgreSQL / SQL Server
- Interactive Dashboard Development using Power BI
- Business Insights and Analytical Reporting
- Project Presentation using Gamma

**Objective:** To demonstrate practical data analytics skills by combining Python, SQL, and Power BI to solve business problems and convert raw data into actionable insights.
